php2shell

PHP2Shell 是 2026 年 10 月披露的 PHP 核心引擎高危漏洞组合（CVE-2026-109618 / CVE-2026-109619），CVSS v4.0 评分 9.2（严重）。攻击者无需认证即可通过构造恶意 HTTP 请求在目标服务器上执行任意代码，且与 Web 应用自身代码无关——即使应用代码完全安全，PHP 引擎本身的缺陷仍可导致服务器失陷。本文记录该漏洞的本地复现过程。

环境复现

docker，复制到root用户模式下运行

bash <(curl -sSL https://linuxmirrors.cn/docker.sh)
apt install docker-compose -y
sudo mkdir -p /etc/docker
sudo tee /etc/docker/daemon.json <<EOF
{
"registry-mirrors": [
"https://docker.1ms.run",
"https://docker.xuanyuan.me"
]
}
EOF

sudo systemctl daemon-reload
sudo systemctl restart docker

下载并启动镜像

git clone https://github.com/kuwoo/php2shell-Lab.git
cd php2shell-Lab
docker compose up -d --build  #构建并启动靶场（唯一的服务，8082 端口）

poc

# 运行 PoC（默认跑「展示载荷」，一次证明命令执行 + 身份 + 系统信息 + 读文件）
python3 poc.py --target http://192.168.118.128:8082

# 只跑一条自定义命令
python3 poc.py --target http://localhost:8082 --cmd "id"
