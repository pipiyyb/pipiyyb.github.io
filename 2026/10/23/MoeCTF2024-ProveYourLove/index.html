ProveYourLove

初步判断

这道题访问进去页面就是需要用户输入信息然后发送表白的功能，这里注意提示说要300份表白才行

当我们再次提交发现只允许提交一次，目前表白份数也是1

那么优先考虑是不是前端js代码进行的判断处理，现在我们f12查看源代码下面的js文件

分析java script代码

根据前面的弹窗提示 “您已经提交过表白，不能重复提交”，我们可以快速定位下关键处理代码

这里做了一个检查，当我们第一次提交表白的时候会把键 confessionSubmitted 的值设为字符串 'true'，存进浏览器的 localStorage

科普

localStorage 是浏览器提供的一个本地键值存储空间，用来在用户电脑上持久保存字符串数据。

那么我们再次请求的时候会发现它对本地浏览器存储的confessionSubmitted 进行检查是否存在，存在就不允许再次告白了

我们手动找到具体存放位置看看

绕过检查

有个很直接的办法就是直接移除掉，我们通过外部去进行访问请求即可，因为它本身只是这个浏览器本地存储而已，只是局部范围，我们先让其恢复可以发送告白请求状态，然后使用burp进行抓到成功请求的数据包然后多次利用即可，可以绕过整个前端

// 浏览器控制台执行，删掉标记
localStorage.removeItem('confessionSubmitted');

或者手动找到这个位置把true改掉或者直接删掉这个confessionSubmitted 健即可，随便选一种就可以进行抓包

burp抓包利用

这里可以借助里面的爆破模式 Intruder

目的只是帮我省去手动一个一个重发直接爆破300下就行了，等同于请求了300下

点击开始进攻

回到浏览器查看

成功获取，说白了本质就是能获取到请求包然后模拟多次发送就行，那个检查发送js处理也只是浏览器刚开始请求做了一次本地浏览器存储，然后下一次请求就会做检查，直接不管它用curl 或者python requests 都可，下面再来python如何实现

python exp

import requests

def exp(url):
    data = {"nickname": "1", "user_gender": "male", "target": "1", "target_gender": "male", "message": "1",
            "anonymous": "false"}

    response = requests.post(url, json=data)
    if response.status_code == 200:
        return True


if __name__ == '__main__':
    url = "http://59.54.91.55:32775/questionnaire"
    sum = 0
    for i in range(300):
        result = exp(url)
        if result:
            sum += result
            print(f"已经发送{sum}")
